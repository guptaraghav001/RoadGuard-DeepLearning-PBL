# RoadGuard — Deep Learning PBL

## Project Title
Urban Pothole and Road Damage Assessment System Using Deep Learning

## Project Overview
RoadGuard is an individual university Deep Learning PBL project that aims to detect, classify, and assess road surface damage using computer vision and deep learning.

## Technology Stack
- Java 17
- Apache Maven
- Deep Java Library (planned)
- OpenCV (planned)
- Google Colab / Kaggle for cloud experiments

## Dataset
RDD2022ES — Road Damage Detection Extended Severity Dataset.

The dataset contains 25,600 images, including 12,800 mirrored images, across eight road damage categories.

## Current Progress
